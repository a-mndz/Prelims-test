# Requirements & Setup

This application is a Node.js project and uses only standard-library modules.
- Runtime requirement: Node.js >= 22
- Optional production requirement: PostgreSQL database service
- No third-party npm packages are declared in `package.json`.

## Install Steps
1. Install Node.js >= 22
2. From the `server` directory, run `npm install` (no external dependencies are declared)
3. For production, provision PostgreSQL and configure `DATABASE_URL`
